The work of this group is clearly described in its charter:

The Benchmarking & Performance Measurements Working Group (BPM WG) develops and maintains metrics, methodologies, and protocols that can be applied to the quality, performance, reliability, and scalability of data delivery services and applications running over public or private networks using IETF technologies. These metrics, methodologies, and protocols can be used by network operators and end users in production or independent testing groups in lab environments. Benchmarking measurements in a lab environment aim to assess the benchmarks for network devices, systems, and services by using isolated and highly controlled stimuli, while performance measurements in a production environment seek to evaluate the network performance of services and applications under live and variable operational conditions.
