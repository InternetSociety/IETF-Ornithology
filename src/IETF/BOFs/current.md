#  Continuous Updating and Ratcheting for Rekeying Encrypted Network Transport (current)
* <IETFschedule meets=true>IETF126: Tue 21 Jul 2026 16:30 - Grand Park Hall 3</IETFschedule>
* [BoF request](https://datatracker.ietf.org/doc/bofreq-housley-continuous-updating-and-ratcheting-for-rekeying-encrypted-network-transport/)
* Potentially of interest because: strengthening the security properties of protocols.
* Keywords: Encryption, Security

Messaging Layer Security (MLS) is a security layer for end-to-end encrypted messages which has been developed in the IETF. MLS can be used by other protocols to perform key management tasks. MLS based key management provides asynchronous key updates, forward secrecy (FS), and post-compromise security (PCS). Properties that are expected of a modern key management protocol. The intent is to specify a protocol for this purpose. 

This is a working group forming BoF for which the charter can be found [in this Google doc](https://docs.google.com/document/d/1f8KDExti7Eo_LvRFIZyHKJcpVUXF0Et8vDPo5nPdRGY).
